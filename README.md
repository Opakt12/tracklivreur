# TrackLivreur

Application native Android de tracking GPS temps réel avec anti-fraude.

## Features
- Role-based (Merchant, Driver, Viewer)
- Live GPS Tracking
- Fraud Detection
- Supabase Backend
- Jetpack Compose UI

## Tech Stack
- Kotlin + Jetpack Compose
- Supabase (Auth, Realtime, Database)
- Google Maps Compose
- Foreground Service for GPS
